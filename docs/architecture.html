Les fichiers générés et l’endroit où écrire votre code.

Un dossier par ressource

arborescence
src/
├── main.rs                  # Démarrage du serveur
├── lib.rs                   # État partagé et assemblage des routes
├── config.rs                # Configuration d’environnement
├── database.rs              # Pool SQL et migrations
├── error.rs                 # Réponses d’erreur
├── patch.rs                 # Champ omis / NULL / valeur
└── resources/
    ├── mod.rs               # Registre géré par Miblo
    └── user/
        ├── mod.rs           # Routes de User
        ├── handlers.rs      # Extraction HTTP et réponses
        ├── model.rs         # Structure des données
        ├── requests.rs      # Requêtes et validation
        ├── service.rs       # Règles métier
        └── repository.rs    # SQL et transactions

Les migrations sont dans migrations/. Les routes supplémentaires sont dans src/resources/custom_routes/. Le README généré explique la configuration, les fichiers et les requêtes en français.

Où écrire votre logique ?

BesoinFichier
Règle métierservice.rs
Validation des requêtesrequests.rs
Requête SQLrepository.rs
Extraction et réponse HTTPhandlers.rs
Routes branchées à la mainsrc/lib.rs, hors des registres gérés

Une écriture suit handler → service → repository. Le code est formaté avec rustfmt et accompagné de commentaires ciblés.

Un projet autonome

shell
cargo check
cargo test
cargo run

L’API fonctionne sans Miblo. Les requêtes SQLx sont exécutées à l’exécution : compiler ne demande pas de base vivante ni de dossier .sqlx. Un lockfile conserve les dépendances.

Le socle contient des tests de santé et de désérialisation PATCH ainsi que des tests de validation des requêtes dans l’architecture actuelle. Ajoutez les tests propres à votre métier.

Les fichiers gérés par Miblo

Versionnez miblo.yaml et .miblo/state.json avec vos sources. Ils conservent la définition, les versions épinglées et les bases de fusion.

Les registres src/resources/mod.rs et custom_routes/mod.rs sont gérés par Miblo. Y écrire du métier peut bloquer les ajouts. Personnalisez les fichiers de ressources ou le branchement dans src/lib.rs.
