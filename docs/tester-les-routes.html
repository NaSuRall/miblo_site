Tester les routes

Choisir une route, modifier les valeurs du formulaire et envoyer.

▶ Voir la démo →

Envoyer un POST

  1. Lancez l’API avec r. Dans Routes, sélectionnez le POST, puis x.
  2. Le formulaire Préparer la requête contient les champs du modèle.
  3. Avec les flèches, choisissez une valeur. Entrée l’édite.
  4. Revenez sur Envoyer la requête et appuyez sur Entrée.

Vous n’avez pas de JSON à saisir. Les champs facultatifs commencent à NULL, les champs privés sont masqués et id est exclu. Les valeurs d’exemple uniques changent à chaque préparation.

Modifier avec PATCH

Commande du formulaireEffet
EntréeModifier la valeur sélectionnée.
EspaceInclure ou exclure le champ.
nChoisir NULL pour un champ facultatif.
DébutRevenir sur Envoyer la requête.
ÉchapFermer la saisie ou annuler la requête.

Les champs d’un PATCH commencent exclus : ils gardent leur valeur en base. Incluez ceux à modifier. Un PATCH vide est refusé.

Choisir une référence existante

Les clés étrangères proposent jusqu’à 20 lignes obtenues via la collection du modèle cible. Une référence obligatoire est présélectionnée si une ligne existe.

Sinon, créez d’abord la ligne cible ou saisissez un identifiant existant. Le testeur ne crée pas de ligne liée automatiquement. Une référence facultative peut rester NULL.

Requêtes et formulaires libres

f ouvre une requête libre : GET, POST, PATCH, PUT, DELETE, HEAD ou OPTIONS. Les chemins CRUD connus retrouvent leurs champs. + ajoute un champ texte, entier, décimal ou booléen ; Suppr le retire.

Une route personnalisée liée à un modèle utilise ses champs comme suggestion modifiable, pas comme contrat déduit. Les champs du formulaire ne modifient pas vos modèles.

Les payloads imbriqués, l’inférence des types Rust écrits manuellement et les en-têtes d’authentification personnalisés ne sont pas encore pris en charge. Utilisez un client HTTP externe pour ces besoins.

Lire le résultat

Miblo affiche code HTTP, durée et réponse formatée. Délai maximal : 10 secondes ; corps affiché : 64 Kio ; redirections non suivies.

Aucune écriture avant l’action explicite Envoyer. Une suppression sans corps demande confirmation. Échap revient en arrière ou annule.

CodeInterprétation
200 / 201 / 204Lecture ou modification / création / suppression sans contenu.
400 / 422Valeur, structure JSON ou type à vérifier.
404Route ou ligne introuvable.
409Contrainte d’unicité ou de clé étrangère.
501Fonction personnalisée à compléter.
