SQLite et MySQL

SQLite se configure automatiquement. MySQL nécessite un serveur et une connexion.

SQLite

Choisissez SQLite à la création. L’interface prépare .env, crée miblo.sqlite et applique les migrations initiales. Aucun serveur supplémentaire n’est requis.

Opération dans MibloMigration SQLite
Créer le projetAppliquée automatiquement.
Ajouter un modèle, API arrêtéeAppliquée automatiquement.
Modifier un modèle avec mÀ appliquer avec b ou au prochain lancement de l’API.
.env
DATABASE_URL=sqlite://miblo.sqlite?mode=rwc

L’API générée crée aussi le fichier manquant et applique les migrations au démarrage.

MySQL

  1. Démarrez un serveur MySQL, puis choisissez MySQL à la création du projet.
  2. Renseignez hôte, port, base, utilisateur et mot de passe dans Miblo.
  3. Validez Enregistrer la connexion MySQL ?. Elle est écrite dans .env.
  4. Dans b, choisissez Initialiser la base et ses tables et confirmez.

Le compte MySQL doit avoir les droits nécessaires à l’opération. Miblo ne démarre pas le serveur MySQL.

Utiliser le compose.yaml fourni

Pour le développement local, le projet contient un service MySQL. Utilisez les paramètres de .env.example pour cette connexion.

shell
docker compose up -d db
# Une fois MySQL prêt :
miblo db init
miblo run

Les actions sur la base

CommandeEffet
miblo db checkVérifie la connexion.
miblo db initInitialise la base si nécessaire et applique les migrations.
miblo db migrateApplique les migrations en attente.
miblo db schemaAffiche le schéma réel en JSON.

--project PATH permet de travailler depuis un autre dossier. Les mots de passe ne sont pas passés comme arguments.

Configuration et limites

Les commandes BDD de Miblo lisent d’abord DATABASE_URL dans le .env du projet, puis dans l’environnement si absent du fichier. L’API générée utilise sa configuration d’exécution ; évitez deux valeurs différentes entre fichier et shell.

Le moteur est fixé à la création. Passer de SQLite à MySQL nécessite une migration de code et de données séparée. Le schéma distingue base réelle et modèles déclarés.
