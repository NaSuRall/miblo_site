Ce que Miblo génère

Un projet Rust avec Axum pour les routes HTTP et SQLx pour SQLite ou MySQL. Les sources restent éditables et se lancent avec Cargo.

Version documentée

CLI 0.9.1, templates 0.6.0. La génération concerne Rust. Node.js et OpenAPI ne sont pas disponibles.

Miblo fournit la structure. Les règles métier, l’authentification et le déploiement restent à développer dans votre projet.

L’application démarre en anglais. Maj+L permet de choisir Français ou English, avec un choix mémorisé. Choisir la langue →
