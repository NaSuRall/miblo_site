Créer une API

Un projet SQLite, un modèle User et une première requête POST.

▶ Voir la création dans Miblo →

1. Créer le projet

shell
miblo
  1. Appuyez sur n et saisissez team-api.
  2. Validez un dossier qui n’existe pas encore, puis le port 3000.
  3. Choisissez SQLite — fichier local, configuration automatique.
  4. Choisissez GitHub Releases, puis Créer le projet.

Le projet et le fichier miblo.sqlite sont créés. L’état BDD affiche Migrations à jour.

2. Ajouter User

  1. Appuyez sur a et saisissez User.
  2. Ajoutez name, type Texte court, sans option.
  3. Choisissez Ajouter un autre champ : email, type Texte court. Cochez Unique avec Espace.
  4. Choisissez Terminer et générer, validez /users, puis Générer.

Miblo crée la table users avec sa clé id, le code Rust et les cinq routes CRUD. L’API étant arrêtée, la migration SQLite est appliquée automatiquement.

3. Envoyer un POST

  1. Appuyez sur r et attendez API en cours.
  2. Passez au panneau Routes avec Tab, sélectionnez POST /users, puis x.
  3. Les champs sont déjà remplis. Entrée permet de modifier une valeur.
  4. Sélectionnez Envoyer la requête puis Entrée. La réponse est HTTP 201.
  5. Testez GET /users pour retrouver la ligne créée.

s arrête l’API. La première compilation prend plus de temps que les lancements suivants.

Le même parcours dans le shell

shell
miblo new team-api --database sqlite --yes
cd team-api
miblo add User name:string email:string:unique --yes
miblo db init
miblo run

Ouvrez ensuite miblo dans un second terminal, depuis team-api, pour tester les routes. L’API lancée ailleurs est signalée comme externe.

Suite du projet

m pour ajouter un champ, g pour créer une route, d pour voir le schéma et e pour ouvrir le code.
