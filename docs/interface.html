Choisir la langue de Miblo

Depuis la version 0.9.1, Miblo démarre en anglais, quelle que soit la langue du système.

  1. Appuyez sur Maj+L (L majuscule), ou ouvrez Espace → Language / Langue.
  2. Choisissez Français ou English avec les flèches, puis Entrée.

:language et :langue ouvrent le même menu. Le changement est immédiat et le choix est conservé au prochain lancement. Le projet reste ouvert et l’API continue à tourner.

Les menus, formulaires, aides et états changent de langue. Vos fichiers générés, données SQL et anciens logs gardent leur contenu. Les noms de commandes et --help restent en anglais ; les commentaires et le README générés suivent la langue du template.

Le sélecteur EN / FR du site change uniquement la documentation. Pour Miblo, utilisez le menu de l’application. Préférences et variables de langue →

La barre de commandes

Appuyez sur : pour saisir une commande :

commandes de l’interface
:new    :open chemin/du/projet    :add    :model
:run    :stop    :db    :migrate    :schema    :templates
:routes    :route-new    :route    :request    :code
:check    :test    :doctor    :edit    :refresh    :theme
:language    :langue    :help    :quit

Ces commandes internes ne sont pas toutes des sous-commandes du CLI. Pour vos scripts, consultez la référence CLI.

Lire les états

CouleurAPIBase de données
● VertLe contrôle HTTP répond.Connexion et migrations à jour.
● OrangeDémarrage ou redémarrage requis.Initialisation ou migration à appliquer.
● RougeErreur de processus ou de réponse.Connexion impossible ou migration incohérente.
● GrisAPI arrêtée ou aucun projet.Vérification en attente ou aucune base.

Les états sont contrôlés environ toutes les trois secondes. Une API externe est identifiée comme telle ; Miblo ne l’arrête pas.

Éditeur, animation et fermeture

e utilise VISUAL, puis EDITOR, puis vi sur Unix ou notepad sur Windows. Les arguments sont acceptés, par exemple EDITOR="code --wait". Le terminal est restauré pendant l’édition.

Une touche passe l’animation bleue ; MIBLO_NO_ANIMATION=1 la désactive. Trois thèmes sont proposés pour la session.

La fermeture normale arrête les processus lancés par Miblo. Terminez les générations, compilations et requêtes en cours avant de quitter : la fermeture est bloquée pendant ces opérations.
