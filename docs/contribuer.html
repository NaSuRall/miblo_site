Contribuer

Le CLI, les templates et ce site sont open source sous licence MIT.

Les dépôts

  • Miblo : CLI, TUI, génération et gestion des projets.
  • miblo_templates : packs Handlebars et archives publiées.
  • miblo_site : ce site et sa documentation.

Signalez une erreur, proposez une amélioration ou contribuez aux sources via GitHub.

Vérifier le CLI

shell
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked

Les scripts du dépôt couvrent aussi l’installation, la génération, les migrations, le CRUD SQLite/MySQL et le TUI. Les dépendances de test sont listées dans scripts/requirements-test.txt.

Tester une API générée

Avec CLI et templates dans des dossiers voisins :

shell
cargo build --locked
python3 scripts/smoke_sqlite.py \
  --miblo target/debug/miblo \
  --templates ../miblo_templates/rust_sqlite_template_v4 \
  --target-dir target/sqlite-smoke

Ces tests créent leurs projets et données temporaires. Consultez le README de la branche de développement pour les parcours MySQL, TUI et installation et leurs dépendances.

Avant une publication

Vérifiez l’installation, la génération depuis les releases, les migrations et la préservation des modifications manuelles. Le test automatisé du TUI tourne sur Unix ; vérifiez également le terminal Windows.

Le CLI, les templates et le site se publient séparément. Les instructions de chaque dépôt décrivent leurs contrôles.
