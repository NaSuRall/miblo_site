Installation

Installez Miblo avec Cargo ou téléchargez le binaire Windows, macOS ou Linux. Rust, Cargo et rustfmt restent nécessaires pour les API.

Préparer votre environnement

Installez Rust 1.88 ou ultérieur, Cargo et rustfmt via rustup. Le formateur sert à générer et fusionner les sources Rust.

shell
rustup update stable
rustup component add rustfmt
rustc --version
cargo --version
SystèmeOutils natifs nécessaires
macOSCommand Line Tools : xcode-select --install
LinuxCompilateur C/C++ et éditeur de liens ; par exemple build-essential sur Debian/Ubuntu.
WindowsVisual Studio Build Tools, option « Développement Desktop en C++ », et chaîne Rust MSVC.

SQLite ne nécessite aucun serveur supplémentaire. Python, Docker et sqlx-cli ne sont pas nécessaires pour utiliser Miblo.

Installer

shell
cargo install miblo --locked
miblo --version

Cette commande installe ou met à jour Miblo vers la version documentée. La compilation peut prendre plusieurs minutes. --locked utilise les versions de dépendances testées.

Installer depuis un clone du dépôt
shell
cargo install --path . --locked

Lancer Miblo

shell
miblo

La commande ouvre l’interface en anglais par défaut. Pour suivre les menus de ce guide en français, appuyez sur Maj+L, choisissez Français puis Entrée. Le choix est conservé. Si le dossier courant contient miblo.yaml, le projet est ouvert automatiquement.

En ligne de commande
shell
miblo ui --project chemin/vers/mon-api

Sans terminal interactif, miblo affiche l’aide. Les sous-commandes restent utilisables dans vos scripts.

Binaires prêts à télécharger

Choisissez votre système pour télécharger Miblo 0.9.1 bêta déjà compilé :

  • Windows x64 · SHA-256
  • macOS Apple Silicon · SHA-256
  • macOS Intel · SHA-256
  • Linux x64 (glibc 2.35+) · SHA-256

Décompressez l’archive, puis placez miblo (ou miblo.exe) dans un dossier de votre PATH. Sous macOS/Linux, conservez le droit d’exécution du fichier. Lancez ensuite miblo --version dans un terminal.

Rust, Cargo, rustfmt et les outils natifs restent nécessaires pour compiler les API générées. Les binaires de cette bêta ne sont pas signés ni notariés ; l’installation avec Cargo compile Miblo depuis ses sources.

Notes de version et toutes les archives. Les templates sont téléchargés automatiquement au premier usage.

Si la commande est introuvable

Ouvrez un nouveau terminal et vérifiez le dossier des binaires Cargo dans votre PATH : généralement ~/.cargo/bin sur Unix et %USERPROFILE%\.cargo\bin sur Windows.

Si la compilation échoue à l’édition de liens, vérifiez les outils natifs du système. Pour les autres erreurs, consultez le dépannage.
