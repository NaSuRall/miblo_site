Dépannage

Les erreurs courantes et les actions pour les résoudre.

Faire un diagnostic

shell
miblo doctor --project team-api
miblo db check --project team-api

doctor vérifie le projet et ses prérequis. db check vérifie la connexion. Consultez le panneau Logs pour le détail d’une erreur.

Template indisponible ou erreur 404

Vérifiez la version, la source et l’accès aux releases. Pour une URL personnalisée, archive et sidecar .sha256 doivent exister.

L’interface propose de changer de source ou réessayer sans perdre nom, destination et port. Un échec de téléchargement ne crée pas le projet.

Template changed since project creation

Le pack local épinglé a changé ou est indisponible. Restaurez son contenu exact pour les modèles qui en dépendent. Pour les prochains ajouts, choisissez un pack publié via u ou :

shell
miblo template update --project team-api

Cette mise à jour ne réécrit pas les anciens modèles ni leur historique. Ne supprimez pas les métadonnées pour contourner le contrôle.

La route renvoie 501

La route utilise Logique personnalisée. Sélectionnez-la, appuyez sur e et complétez service.rs, puis redémarrez.

Pour utiliser directement le SQL d’un modèle, créez une route en choisissant ce modèle et une action CRUD : lister, consulter, créer, modifier ou supprimer.

La base est orange ou rouge

État affichéAction
Mise à jour BDD requiseArrêter l’API, puis b → Appliquer les migrations.
Base à initialiserb → Initialiser la base et ses tables.
Base inaccessibleVérifier la connexion ; pour MySQL, le serveur et ses accès.
Migration incohérenteRestaurer la migration déjà appliquée, puis créer une nouvelle migration pour le changement.

Conflit ou opération interrompue

Un fichier déjà présent, un registre modifié ou du code incompatible avec la fusion bloque la génération. Résolvez les fichiers indiqués avant de relancer. Placez les branchements manuels dans src/lib.rs.

Une interruption peut laisser .miblo/operation.lock et des écritures partielles. Vérifiez qu’aucune opération ne tourne, inspectez le diff et restaurez un état cohérent, puis retirez le verrou obsolète. Les écritures multifichiers ne sont pas une transaction atomique.

Compilation, port ou commande introuvable

Installez rustfmt avec rustup component add rustfmt. Pour l’édition de liens, vérifiez les outils C/C++. Pour un port occupé, changez SERVER_PORT, rafraîchissez avec F5 puis redémarrez.

Vérifiez le PATH Cargo pour une commande introuvable. Dans une issue, fournissez version, système, commande et erreur, sans votre .env privé.
