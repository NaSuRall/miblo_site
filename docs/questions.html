Miblo CLI : questions fréquentes

Ce que Miblo génère, les bases prises en charge et comment utiliser l’API Rust obtenue.

Qu’est-ce que Miblo CLI ?

Miblo CLI est un générateur d’API Rust gratuit et open source, utilisable depuis une interface dans le terminal. Il génère un projet Axum, les requêtes SQLx, les modèles, les routes CRUD et les migrations SQL pour SQLite ou MySQL. Le code reste dans votre projet et vous pouvez le modifier.

Comment créer une API Rust avec une base de données ?

Installez Miblo, lancez miblo, puis appuyez sur n. Choisissez SQLite pour configurer automatiquement une base locale, ou renseignez votre connexion MySQL. Ajoutez un modèle avec a pour générer sa table et ses routes CRUD. Suivre le tutoriel de l’API User →

Les routes générées exécutent-elles des requêtes SQL ?

Oui. Un modèle génère des routes pour lister, consulter, créer, modifier et supprimer des lignes avec SQL. À la création d’une route, choisissez un modèle et une action CRUD pour les réutiliser. Une route de logique personnalisée renvoie HTTP 501 tant que vous n’avez pas complété son service. Routes liées aux modèles et handlers personnalisés →

Peut-on modifier le code Rust généré ?

Oui. Chaque ressource sépare les handlers HTTP, les types de requêtes, les services et l’accès SQL. Ouvrez ces fichiers dans votre éditeur depuis Miblo. L’ajout de modèles préserve les ressources existantes ; une mise à jour s’arrête si elle rencontre des modifications manuelles incompatibles. Voir la structure générée →

Est-ce un outil no-code ou un générateur par IA ?

Miblo utilise des templates versionnés. Il ne nécessite ni modèle d’IA, ni clé API, ni abonnement. Il crée la structure du backend ; vous développez les règles métier et la sécurité en Rust. La version 0.9.1 prend en charge Rust, Axum, SQLite et MySQL. Node.js, PostgreSQL et la génération OpenAPI ne sont pas disponibles actuellement.

L’API générée est-elle prête pour la production ?

Elle fournit un point de départ pour le développement. L’authentification, les autorisations, la validation propre à votre application et le déploiement restent à votre charge. Miblo vous aide à construire et tester la structure, les modèles et la base ; il ne déploie pas votre API.

Où télécharger Miblo ?

Utilisez cargo install miblo --locked, ou téléchargez un binaire Windows x64, Linux x64, macOS Apple Silicon ou macOS Intel. Rust, Cargo, rustfmt et les outils de compilation natifs restent nécessaires pour compiler les API générées. L’interface démarre en anglais ; Maj+L permet de choisir français ou anglais.
