Configuration

Les fichiers et variables utilisés par Miblo et par l’API générée.

Les fichiers importants

FichierRôle
miblo.yamlDéfinition version 1 : projet, modèles, champs et routes.
.miblo/state.jsonPacks épinglés, empreintes et bases de fusion.
.miblo/backups/Copies des sources remplacées lors des évolutions.
.envConfiguration privée d’exécution.
.env.exampleExemple partageable.
migrations/Historique SQL versionné.
Cargo.lockVersions des dépendances.

Versionnez sources, migrations, miblo.yaml et .miblo/state.json. Le .env privé est masqué dans l’explorateur ; .env.example reste visible.

Variables d’environnement

VariableRôle
DATABASE_URLConnexion de l’API ; repli des commandes BDD si le .env ne la définit pas.
SERVER_ADDRESS / SERVER_PORTÉcoute du serveur ; rafraîchir après modification.
MIBLO_TEMPLATE_DIRPack local de développement.
MIBLO_TEMPLATE_BASE_URLDistribution des packs.
MIBLO_CACHE_DIRCache des templates.
VISUAL / EDITORÉditeur et arguments.
MIBLO_NO_ANIMATIONDésactive l’animation lorsque définie.

Pour l’adresse surveillée par le TUI, l’environnement prime sur .env, puis sur le projet. Une adresse d’écoute générique est vérifiée via loopback. Évitez les configurations contradictoires.

Créer depuis une définition

Un fichier YAML peut décrire un nouveau projet :

miblo.yaml
schema_version: 1
name: team-api
stack: rust-axum-sqlite
port: 3000
resources:
  - name: User
    path: /users
    fields:
      - name: name
        type: string
shell
miblo new --config chemin/vers/miblo.yaml --yes

Le dossier de destination doit être libre. Modifier ce fichier dans un projet existant ne migre pas la base : utilisez miblo edit pour ajouter des champs.

Versions des projets

FormatVersion
Définition miblo.yamlschema_version: 1
Templates actuelsPack 0.6.0, format 3
Formats de templates lus par le CLI1, 2 et 3

Un projet peut contenir des modèles issus de plusieurs packs. Les anciens config.yaml ne se convertissent pas automatiquement. Le changement de moteur, les renommages et les suppressions demandent une migration manuelle.
