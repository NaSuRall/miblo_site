Create a REST API in Rust

Create a REST API with Rust, Axum and SQLite: generate a User model and CRUD routes, then test a POST request with Miblo.

▶ Watch the demo →

1. Create the project

shell
miblo
  1. Press n and enter team-api.
  2. Choose a directory that does not exist yet, then port 3000.
  3. Select SQLite — local file, automatic setup.
  4. Choose GitHub Releases, then Create project.

Miblo creates the project and miblo.sqlite. The database status reads Migrations up to date.

2. Add User

  1. Press a and enter User.
  2. Add name, type Short text (255 characters), with no options.
  3. Select Add another field: email, also short text. Toggle Unique with Space.
  4. Select Finish and generate, accept /users, then Generate.

Miblo creates the users table with an id primary key, Rust code and five CRUD routes. With the API stopped, the new SQLite model migration is applied automatically.

3. Send a POST

  1. Press r and wait for API running.
  2. Use Tab to reach Routes, select POST /users, then press x.
  3. The fields are prefilled. Press Enter to edit a value.
  4. Select Send request and press Enter. The response is HTTP 201.
  5. Test GET /users to retrieve the created row.

s stops the API. The first Rust build takes longer than subsequent starts.

The same steps in the shell

shell
miblo new team-api --database sqlite --yes
cd team-api
miblo add User name:string email:string:unique --yes
miblo db init
miblo run

Open miblo in a second terminal inside team-api to test routes. An API started elsewhere is identified as external.

Continue building

Press m to add a field, g to create a route, d to inspect the schema, or e to open the code.
