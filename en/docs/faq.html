Miblo CLI: questions and answers

What Miblo generates, which databases it supports and how to use the resulting Rust API.

What is Miblo CLI?

Miblo CLI is a free, open-source Rust API generator with an interactive terminal interface. It generates an Axum project, SQLx queries, models, CRUD routes and SQL migrations for SQLite or MySQL. The generated source belongs in your project and stays editable.

How do I create a Rust API with a database?

Install Miblo, run miblo and press n. Choose SQLite for automatic local database setup, or supply your MySQL connection. Add a model with a to generate its table and CRUD endpoints. Follow the User API tutorial →

Does Miblo generate working SQL routes?

Yes. A model generates list, read, create, update and delete endpoints backed by SQL queries. When adding a route, choose a model and a CRUD action to reuse them. A custom business-logic route returns HTTP 501 until you implement its service. Model routes and custom handlers →

Can I edit the generated Rust code?

Yes. Each resource separates HTTP handlers, request types, services and SQL access. Open it in your editor from Miblo. Adding models preserves existing resources; model updates stop when they encounter incompatible manual changes. Explore the generated structure →

Is this a no-code tool or an AI code generator?

Miblo uses versioned templates. It does not need an AI model, API key or subscription. It scaffolds your backend; you write business rules and security in Rust. Version 0.9.1 supports Rust, Axum, SQLite and MySQL. Node.js, PostgreSQL and OpenAPI generation are not currently supported.

Is the generated API ready for production?

It is a development starting point. Authentication, authorization, application-specific validation and deployment are your responsibility. Miblo helps you build and test the initial structure, models and database; it does not deploy the API for you.

Where can I download Miblo?

Use cargo install miblo --locked, or download a Windows x64, Linux x64, macOS Apple Silicon or macOS Intel binary. Rust, Cargo, rustfmt and native build tools are still needed to build the generated APIs. The interface starts in English; Shift+L switches between English and French. Downloads and requirements →
