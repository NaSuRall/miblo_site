Documentation

Install Miblo, create a Rust API and manage its models from your terminal.

What Miblo generates

A Rust project with Axum for HTTP routes and SQLx for SQLite or MySQL. The source is yours to edit and runs with Cargo.

Documented version

CLI 0.9.1, templates 0.6.0. Miblo generates Rust APIs. Node.js and OpenAPI generation are not available.

Miblo provides the structure. You implement business rules, authentication and deployment in the generated project. Miblo starts in English. Choose English or French with Shift+L; the preference is saved. These guides use the English menu labels. Generated comments and README files still follow the template pack’s language.
