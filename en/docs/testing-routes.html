Test HTTP routes

Send POST and PATCH requests with prefilled forms, and inspect HTTP responses inside Miblo.

▶ Watch the demo →

Send a POST

  1. Start the API with r. Select a POST route and press x.
  2. Prepare request shows the model fields.
  3. Use arrows to choose a value and Enter to edit it.
  4. Select Send request and press Enter.

You do not write JSON. Optional fields start at NULL, private values are masked and id is excluded. Unique example values change for each new request draft.

Update with PATCH

Form keyEffect
EnterEdit the selected value.
SpaceInclude or exclude a field.
nSet an optional field to NULL.
HomeReturn to Send request.
EscapeClose input or cancel the request.

PATCH fields start excluded and retain their database values. Include only the fields you want to change. Empty PATCH requests are rejected.

Choose an existing reference

Foreign keys offer up to 20 rows fetched through the target model’s collection endpoint. A required reference is preselected when a row is available.

Otherwise create the target row first or enter an existing ID. The tester never creates a related row automatically. Optional references can stay NULL.

Custom requests and forms

f opens a custom request: GET, POST, PATCH, PUT, DELETE, HEAD or OPTIONS. Known CRUD paths receive their model fields. + adds a text, integer, decimal or boolean field; Delete removes it.

For custom routes associated with a model, fields are editable suggestions, not an inferred request contract. Form edits do not change your models.

Nested payloads, inference from handwritten Rust types and custom authentication headers are not supported yet. Use an external HTTP client for those cases.

Read the response

Miblo shows HTTP status, elapsed time and a formatted response. Timeout: 10 seconds; displayed body: 64 KiB; redirects are not followed.

No write request is sent before you explicitly choose Send. Bodyless DELETE requests ask for confirmation. Escape goes back or cancels.

StatusMeaning
200 / 201 / 204Read or update / created / deleted without content.
400 / 422Check values, JSON shape or types.
404Route or row not found.
409Unique or foreign-key constraint conflict.
501Custom function needs implementation.
